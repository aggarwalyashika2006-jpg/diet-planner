AI Diet Planner

A personalized diet planning web application built with React and Firebase Firestore. The application collects basic user information, calculates estimated calorie requirements, tracks food intake, and provides rule-based diet and recipe recommendations based on the user's goals and preferences.

📌 Project Overview

The AI Diet Planner helps users create a simple personalized diet plan by using information such as:

Age

Sex

Height

Weight

Activity level

Fitness goal

Diet preference

Allergies

Budget

Cuisine preference

The application also allows users to record food intake and compare their total intake with their estimated calorie requirement.

✨ Features

Calculate estimated daily calorie requirements

Calculate recommended protein, carbohydrate, and fat quantities

Generate a basic personalized diet plan

Provide rule-based diet recommendations

Suggest recipes based on diet and cuisine preferences

Consider selected allergies in recipe suggestions

Track food intake and calories

Store user information and diet data in Firebase Firestore

Responsive web interface

Deployed as a live web application using Vercel

🧠 Recommendation Logic

The current version uses rule-based logic for personalization.

For example:

A weight-loss goal can generate a calorie-deficit recommendation.

A weight-gain goal can generate an increased-calorie recommendation.

Vegetarian preferences can suggest foods such as paneer and dal.

Non-vegetarian preferences can suggest foods such as eggs and chicken.

Food intake is compared with the calculated calorie requirement.

Activity level can generate basic activity suggestions.

Note: Despite the project name "AI Diet Planner", the current recommendation system is rule-based and does not use a trained machine-learning model or Sentence-BERT.

💻 Run the Project Locally

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/diet-planner.git

2. Open the project folder

cd diet-planner

3. Install dependencies

npm install

4. Start the development server

npm run dev

The application will normally be available at:

http://localhost:5173/

🔥 Firebase

The application uses Firebase Firestore to store user-related diet planner data.

The stored information can include:

User details

Calculated calories

Macronutrient values

Generated diet plan

Food intake list

Total calories consumed

Recommendations

Security Note

Firebase configuration for a web application may contain a Firebase API key. The API key itself is not treated as a password, but Firestore Security Rules must be configured properly before using the application with real/private user data.

Do not upload passwords, service-account private keys, or other secret credentials to GitHub.

📊 Current Limitations

Calorie calculation is based on the current BMR-based implementation.

Recommendations are rule-based rather than generated by a trained AI/ML model.

The current food database contains a limited number of food items.

Actual profile-image upload through Firebase Storage was not implemented because Firebase Storage required a paid billing plan.

Flask API / Cloud Run integration is not part of the current deployed version.
